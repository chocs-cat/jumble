# Chunk P0001-C05 — reading the settings file

**Goal:** D4 is done. `jumble` and `jumble tui` start from a TOML settings
file at the §5.1 path, checked key by key (DEC-17), with the command line
overriding it per §5.2 (DEC-9) and `--no-config` ignoring it. A broken file
stops the command line with exit 2 and starts the TUI from built-in defaults
with an error toast. After this, P0001 goes on to saving settings (D5).

## Notes for the executor

- `tomllib.load` takes a binary file. Read the bytes yourself
  (`path.read_bytes()`) so `OSError` and decoding are separate steps from
  parsing: `FileNotFoundError` → `{}`, other `OSError` → `can't read`,
  `UnicodeDecodeError` → `not UTF-8`, `tomllib.TOMLDecodeError` → `DETAIL`.
- `isinstance(True, int)` is true in Python; the integer check must exclude
  `bool`.
- TOML arrays may mix types; `charsets` needs every element a `str`.
- Keep `settings_from`'s precedence in one place; the TUI branch and the
  generating branch both call it, so they can't drift.
